# 🎨 JavaScript Background Color Switcher

A simple and interactive **Background Color Switcher** built using **HTML, CSS, and JavaScript**.  
Click on different color buttons to instantly change the background color of the page.

This project is designed to practice **DOM manipulation**, **event handling**, and **basic frontend development**.

---

## 🔗 Live Demo

👉 https://goludheerajm31-arch.github.io/Background-Color-Switcher/

## 🚀 Features

- Change background color by clicking color buttons
- Multiple predefined color options
- Simple and clean UI
- Beginner-friendly JavaScript logic
- Lightweight and fast
